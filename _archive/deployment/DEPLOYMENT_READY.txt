## Quick Start (90 seconds)

```bash
# 1. Navigate to deployment directory
cd /home/opc/lawyer-platform/deployment

# 2. Update environment variables
nano .env.webvale
# Add your API keys, passwords, and credentials

# 3. Setup directories and prerequisites
sudo ./deploy-webvale.sh setup

# 4. Create SSL certificates
sudo ./deploy-webvale.sh ssl
# OR for Let's Encrypt (recommended):
sudo ./deploy-webvale.sh letsencrypt thewebvale.com

# 5. Build Docker images
sudo ./deploy-webvale.sh build

# 6. Start all services
sudo ./deploy-webvale.sh start

# 7. Verify health
sudo ./deploy-webvale.sh health
```

## Troubleshooting

**Services won't start?**
```bash
sudo ./deploy-webvale.sh logs        # Check what's wrong
df -h                                # Check disk space
free -h                              # Check memory
```

**Database won't connect?**
```bash
docker ps                            # Is postgres running?
docker exec webvale-postgres-prod psql -U webvale_app -c "SELECT 1"
```

**SSL certificate issues?**
```bash
openssl x509 -in ssl/certificates/cert.pem -noout -text
sudo ./deploy-webvale.sh letsencrypt thewebvale.com  # Renew
```
