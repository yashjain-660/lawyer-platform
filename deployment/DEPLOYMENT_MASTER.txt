================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: Services won't start
SOLUTION:
  1. Check logs: sudo ./deploy-webvale.sh logs
  2. Verify environment variables: cat .env.webvale
  3. Check disk space: df -h
  4. Check memory: free -h
  5. Restart Docker: sudo systemctl restart docker

ISSUE: Database won't connect
SOLUTION:
  1. Verify PostgreSQL is running: docker ps | grep postgres
  2. Check logs: sudo ./deploy-webvale.sh logs postgres 100
  3. Verify password in .env.webvale
  4. Check database exists: docker exec webvale-postgres-prod psql -U webvale_app -l

ISSUE: SSL certificate error
SOLUTION:
  1. Verify certificate files: ls -la ssl/certificates/
  2. Check certificate expiration: openssl x509 -in ssl/certificates/cert.pem -noout -text
  3. Renew Let's Encrypt: certbot renew --force-renewal
  4. Restart Nginx: docker-compose -f docker-compose.webvale.yml restart nginx

ISSUE: Out of disk space
SOLUTION:
  1. Clean up old logs: sudo find ./logs -mtime +30 -delete
  2. Prune unused Docker images: docker image prune -a
  3. Remove old backups: sudo find ./backups -mtime +30 -delete
  4. Check large files: du -sh ./* | sort -h | tail -10

ISSUE: High CPU usage
SOLUTION:
  1. Check which container: docker stats
  2. View logs: sudo ./deploy-webvale.sh logs [container_name]
  3. Check query performance: database logs
  4. Scale resources: Update docker-compose.webvale.yml
